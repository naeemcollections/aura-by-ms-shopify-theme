# Aura by MS — Shopify theme

Luxury black-and-gold Online Store 2.0 theme for **Aura by MS**.

## Download

On GitHub: **Code → Download ZIP**

Direct zip: https://github.com/naeemcollections/aura-by-ms-shopify-theme/archive/refs/heads/main.zip

Then in Shopify: **Online Store → Themes → Add theme → Upload zip file**

Do not unzip before uploading. If GitHub wraps the files in a folder, Shopify still accepts it.

## Or connect GitHub (best)

Shopify Admin → **Online Store → Themes → Add theme → Connect from GitHub**  
Select this repository. Theme stays in sync with the repo.

## After install

Create collections with these **exact handles**:

- `perfumes`
- `watches`
- `new-arrivals`
- `best-sellers`

Import products: **Products → Import → `products-import.csv`**

Add product photos in Shopify admin (keep the original Aura bottle unchanged).

Navigation: Perfumes, Watches, New arrivals, The house.
